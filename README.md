# 阿發｜接續流程 Streaming 比較

國泰產險智能助理「阿發」的回覆呈現方式 Prototype。以固定劇本展示阿發的逐詞 Streaming 回覆，以及回覆中途出錯（Error）時的補救呈現方式。

左側面板可調整等待時間與「下一則訊息 Error」。

## 上方按鈕

按下會把等待時間設回諮詢 3 秒、流程 1 秒並重新播放，不會改動「下一則訊息 Error」。最後按的那一個會顯示為選取；之後在面板改等待時間或 Error 開關，不會取消選取。開頁預設為「Streaming 示範 2」。

| 按鈕 | 小字 | 劇本 | Error 為「是」時，完整回覆的呈現方式 |
|---|---|---|---|
| Streaming 示範 1 | Error：逐詞淡入 | 班機延誤 | 逐詞淡入 |
| Streaming 示範 2 | Error：整則模糊 | 班機延誤 | 整則（訊息＋牌卡）一起模糊轉清晰 |
| Streaming 示範 3 | Error：錯誤訊息 | 班機延誤 | 不再思考，阿發直接顯示「抱歉目前的系統服務異常，請重新發送訊息或再試一次。」，並預填剛才的訊息供重新傳送 |
| 複雜情境演示 | 查帳單 | 查帳單 | 整則（訊息＋牌卡）一起模糊轉清晰 |

設定在 `index.html` 的 `PRESETS`。重播與「確認」會重新播放目前的劇本。

## 複雜情境演示（查帳單）

標題列為「升級版國泰世華智能助理阿發」＋下拉箭頭，底部聲明為「以本行官網公告為準」。

使用者傳「幫我查帳單」後是一個流程回合（一問多則）：

1. 泡泡「好的，阿發幫你查好了！以下是你 5 月的信用卡帳單明細。」
2. 帳單卡（直接整張出現）
3. 提醒泡泡＋「立即前往：信用卡繳費」連結
4. 送出時間＋讚／倒讚
5. 你可能想問（兩個問題）

Error 為「是」時，第一個泡泡吐完後停留 1 秒就收回（帳單卡尚未出現），再思考後整則模糊轉清晰給出完整回覆。連結與「你可能想問」點了只顯示「僅供展示」。文案與金額、日期皆為展示用範例，在 `index.html` 的 `BILL`。

## 呈現方式

**原則：只有阿發的文字泡泡會 Streaming，其他都直接呈現。** 使用者訊息直接出現；阿發的文字泡泡逐詞淡入（以 `Intl.Segmenter` 切中文詞，每詞淡入 360ms，節奏每字 20ms）；牌卡（申請前請準備、匯款帳戶需求、帳單卡）、快速回覆按鈕、時間／讚、你可能想問都在泡泡文字揭示完成後直接出現，不淡入。例外：Error 後以「整則模糊」呈現時，整則連同牌卡一起模糊轉清晰。節奏常數在 `index.html` 的 `FADE_CHAR_MS`、`FADE_IN_MS`、`BLUR_IN_MS`。

從思考中到回覆完成，輸入列都是停用態：文字「請先點選上方項目再繼續操作」、送出鈕變成半透明的暫停鈕。第 5 回合等待點選快速回覆時也是這個狀態。

## 下一則訊息 Error

左側面板「下一則訊息 Error」（否／是），**開頁預設為「否」**，立即生效，不需要按「確認」，也不會重播。設為「是」時，每則阿發回覆（任一回合，含流程回合）都會：

1. 思考中（依該回合類型的等待秒數）
2. 逐詞淡入，文字出現到一半時整則收回（牌卡尚未出現）
3. 再次思考中（同樣的等待秒數）
4. 依上方所選按鈕的方式給出完整回覆（訊息＋牌卡）

「Streaming 示範 3」例外：第 2 步收回後不再思考，阿發直接顯示錯誤訊息泡泡（文案在 `index.html` 的 `ERROR_MESSAGE`），輸入列預填剛才的使用者訊息；點「傳送」會重跑同一回合（Error 仍為「是」時會再次出錯，改為「否」後重新傳送即可看到正常回覆）。

完全手動：不會自動改回，按上方按鈕、重播或按「確認」也不會改變目前的選擇。

## 等待時間

依回覆類型分開設定，諮詢可選 3／5／10 秒，流程可選 1／5／10 秒，按面板最下方的「確認」後重新播放。

| 類型 | 定義 | 預設 |
|---|---|---|
| 諮詢 | 一問一答，只回一則訊息 | 3 秒 |
| 流程 | 一問多則，例如訊息＋卡片 | 1 秒 |

劇本各回合的分類：

| 回合 | 類型 |
|---|---|
| 1. 我想詢問班機延誤相關問題 | 諮詢 |
| 2. 我要申請（注意事項＋申請前準備卡） | 流程 |
| 3. 本人匯款帳戶有什麼要求（說明＋匯款帳戶需求卡） | 流程 |
| 4. 班機延誤 2 個半小時，可以申請理賠嗎？ | 諮詢 |
| 5. 我想確認同一事故的延誤時間怎麼計算（訊息＋快速回覆按鈕） | 諮詢 |
| 6. 點選快速回覆後的回答 | 諮詢 |

第 5 回合的快速回覆是操作按鈕，不是另一則回答，因此歸為諮詢。

## 劇本

1. 我想詢問班機延誤相關問題 → 常見問題
2. 我要申請 → 理賠注意事項＋申請前準備卡
3. 本人匯款帳戶有什麼要求
4. 班機延誤 2 個半小時，可以申請理賠嗎？
5. 我想確認同一事故的延誤時間怎麼計算 → 快速回覆（查理賠條件／查國泰產險營業據點）

使用者訊息會預先填入，點「傳送」才進入下一輪。

## 結構

```
dist/
  index.html                  # 頁面＋內嵌 JS（全部邏輯都在這）

  assets/
```

## 本機預覽

```bash
npx serve dist
```

或直接用瀏覽器開啟 `dist/index.html`。

## 注意

- 理賠條件、期限、客服電話等文案僅供 Prototype 展示，對外使用前須以國泰產險官網與保單條款核對。
- `app.css` 與 `assets/` 含有其他頁面（登入、註冊、機場搜尋等）的樣式與資源，本頁實際只使用其中一部分。
